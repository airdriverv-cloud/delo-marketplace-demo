# дело — демо-маркетплейс бизнес-услуг

Прототип платформы, собранной по исследованию 100 площадок типа Kwork и ТЗ из файла `100_площадок_и_ТЗ.docx`.

Это не реальный сервис: оплата имитируется, данные форм хранятся только в `localStorage` браузера. Цель — показать продуктовую модель, сценарии и качество интерфейса.

## Что внутри

- **Лендинг** — оффер, поиск, категории, популярные услуги, гарантия, FAQ.
- **Каталог** — 12 услуг, фильтры по категории, цене и рейтингу, поиск, сортировка.
- **Карточка услуги** — 3 тарифа, допуслуги, отзывы, FAQ, расчёт стоимости.
- **Оформление заказа** — модальное окно с демо-оплатой и созданием заказа в escrow.
- **Бриф** — пошаговый мастер из 5 шагов с валидацией и сводкой.
- **Личный кабинет** — заказы, статусы, escrow, приёмка работы, демо-заказ.
- **Исполнителям** — оффер, требования и форма заявки.
- **Документы** — демонстрационная оферта, политика ПД и правила споров.
- **404** — отдельная страница.

## Стек

- HTML5, CSS3, vanilla JavaScript.
- Без сборки и зависимостей — открывается как статический сайт.
- Шрифт Manrope подключается с Google Fonts, есть системный fallback.
- Все изображения — локальные SVG.

## Локальный запуск

```bash
python -m http.server 8787 --directory site
```

Откройте `http://127.0.0.1:8787/`.

Или просто откройте `site/index.html` в браузере: основные сценарии работают, но для корректной загрузки некоторых ресурсов лучше локальный сервер.

## Структура

```text
site/
  index.html          # лендинг
  catalog.html        # каталог и фильтры
  service.html        # карточка услуги
  brief.html          # мастер брифа
  dashboard.html      # личный кабинет
  contractor.html     # страница для исполнителей
  legal.html          # документы
  404.html
  assets/
    styles.css
    app.js
    data.js
    logo.svg
    cover-*.svg
```

## Демо-данные

- 12 услуг в 6 категориях.
- 12 отзывов.
- Заказы и заявки хранятся в `localStorage`:
  - `delo_orders` — заказы;
  - `delo_briefs` — брифы;
  - `delo_applications` — заявки исполнителей.

Очистить данные: настройки браузера → данные сайта.

## Деплой на GitHub Pages

Репозиторий содержит статический сайт в корне. В настройках репозитория:

1. **Settings → Pages**.
2. **Source**: Deploy from a branch.
3. **Branch**: `main`, папка `/ (root)`.
4. Сохранить.

Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

## Ограничения

- Нет реального бэкенда, платежей, KYC и модерации.
- Нет авторизации: личный кабинет — демо-режим.
- Юридические тексты — пример, не юридическая консультация.
- Тарифы и тексты услуг — демонстрационные.
